# Branimo API Documentation

# Endpoint

https://api.branimo.com/getBrand

# Request Description

This endpoint allows you to retrieve brand data based on the provided URL. The request should be sent via an HTTP POST method with the raw request body containing a JSON object with a "url" key.

# Request Body

url (string): The URL for which brand data is to be retrieved.

{
  "url": "https://example.com"
}

# Request Headers

  • APP-ID: 526e5c6e-b624-4713-9857-f7a0ab604b12
  • API-KEY: d153a12978e660e43dc7a6f1032ecdfb18ef612ead5c80366f

# Response

The response will have a status code of 200 and a content type of application/json. The response body will contain a JSON object with the following schema: 

{
  "message": "",
  "brand_data": {
    "id": 0,
    "title": "",
    "slogan": "",
    "description": "",

    "address": "",
    "socials": {
      "twitter": "",
      "youtube": "",
      "facebook": "",
      "linkedin": ""
    },
    "logo_url": "",
    "whois_info": "",
    "industry": "",
    "tech_stack": [""],
    "revenue": "",

    "gpt_company_brief": "",
    "gpt_primary_product": "",

  }
}
